\# Day 87 — AI Learning Path Generator

\#\# What I Built  
An AI tool that takes any skill \+ goal \+ timeline and generates a complete  
week-by-week learning path with Bloom's Taxonomy learning objectives,  
curated resources, weekly milestones, mini tasks, and a capstone project.

\#\# What I Learned  
\- Functions make code reusable — call\_ai() serves every project I build  
\- Bloom's Taxonomy is not just an L\&D concept — it is a prompt engineering  
  technique. Telling the AI to structure outputs by cognitive level  
  produces dramatically better learning designs than generic prompts  
\- JSON structured outputs let me render the same data in multiple ways —  
  progress bars, expandable weeks, download files — all from one API call  
\- st.expander() creates clean collapsible sections for complex outputs

\#\# How I'd Explain This in an Interview  
"I built a learning path generator that applies Bloom's Taxonomy  
programmatically — the AI structures content from Remember through Create  
across weeks automatically. It is a direct combination of my instructional  
design background and my AI development skills. I built it because tools  
like this are exactly what upGrad, Scaler, and Great Learning need  
internally — and I wanted to prove I could build it, not just describe it."
