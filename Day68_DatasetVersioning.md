Dataset versioning

👉 Dataset versioning \= **saving and tracking different versions of your data over time**

* Save each dataset version (v1, v2, v3…)  
* Track what changed (new tickets, updated KB)  
* Compare performance after each update

Think:

Old data → New data → Compare → Decide better version

---

Why versioning matters in AI

* Helps you **track improvements or drops**  
* Makes it easy to **rollback to older data**  
* Ensures **reproducibility** (you know which data gave which result)

👉 Without versioning:

* You won’t know why performance changed ❌
