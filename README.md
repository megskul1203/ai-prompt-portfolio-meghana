## About This Journey

I'm Meghana — a Content Developer (L&D) in Bengaluru, actively transitioning into AI Engineering. This repository documents my daily progression from prompt engineering fundamentals to production-grade AI systems.

**Why this format?** Learning in public creates accountability, and real outputs are the only honest proof of skill.

**Background:** CS Engineering degree → 3 years UPSC prep → Content Developer (L&D) → AI Engineer in training. Days 1–68 were deep concept study. Days 69+ are real running Python code, committed daily.
